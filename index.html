인과 편집기

노드나 화살표를 클릭하면 여기에서 내용을 편집할 수 있습니다.
사용법은 상단의 도움말 버튼을 누르세요.

도움말

  • 빈 곳 더블클릭: 노드 추가 (노드 = 하나의 상태)
  • 노드 드래그: 위치 이동
  • 노드 선택 후 Shift+클릭 다른 노드: 화살표 연결 (원인 → 결과)
  • 화살표를 클릭하면 그 인과의 설명과 메모를 적을 수 있습니다
  • 노드·화살표 선택 후 Delete: 삭제
  • 노드 오른쪽 위 체크박스: 체크하면 그 노드의 테두리가 강조 색으로 바뀝니다
  • 양 끝 노드가 모두 체크된 화살표는 강조 색으로 표시됩니다
  • 노드 편집 칸의 '역할'에서 시작·종료 노드를 정하면, 자동 정렬(계층)의 기준이 됩니다
  • 설정: 노드 모양, 노드 색, 배경 색, 연결선 모양과 색, 체크 강조 색을 바꾸고, JSON 저장·불러오기도 여기서 합니다

설정

노드 색 (안쪽 채우기)
배경 색
연결선 색
체크 강조 색 (테두리와 연결 화살표)
