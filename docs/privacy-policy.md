# 인과 편집기 개인정보처리방침

시행일: 2026년 11월 15일 (파이어폭스 구글 드라이브 동기화 내용 추가: 2026년 11월 15일)

인과 편집기(이하 "확장 프로그램")는 사용자의 데이터를 수집하지 않으며 개발자의 서버로도 전송하지 않습니다.

## 수집하는 정보

없습니다. 개발자는 이름, 이메일, 위치, 방문 기록, 사용 기록 등 어떤 사용자 정보도 수집하지 않습니다. 분석 도구, 광고, 추적 코드도 사용하지 않습니다.

## 데이터 저장 위치

사용자가 편집기에서 작성한 노드, 화살표, 설정, 버전 기록은 다음 두 곳 중 한 곳에만 저장됩니다.

- 사용자의 브라우저 안(IndexedDB). 기본값입니다.
- 사용자가 직접 연결한 컴퓨터의 폴더. 사용자가 선택한 경우에만 사용합니다.

이 데이터는 개발자를 포함한 누구에게도 전송되지 않습니다. 파이어폭스 확장에서 사용자가 구글 드라이브 동기화를 직접 실행한 경우에만 사용자 본인의 드라이브로 전송됩니다(아래 "외부 통신" 참고).

## 외부 통신

기본적으로 확장 프로그램은 외부 서버와 통신하지 않습니다. 외부 스크립트를 내려받아 실행하지도 않습니다. 편집기 화면의 "책 소개" 링크는 사용자가 직접 눌렀을 때만 새 탭으로 열리는 일반 링크입니다.

### 구글 드라이브 동기화 (파이어폭스 확장, 선택 기능)

사용자가 설정에서 "드라이브에 올리기"나 "드라이브에서 받기"를 눌렀을 때만, 사용자 본인의 구글 계정으로 로그인해 구글 드라이브(Google API)와 통신합니다. 이때 노드 파일(.md)이 사용자의 드라이브 "인과편집기" 폴더로 전송되거나 그 폴더에서 내려받아집니다. 요청하는 권한은 이 확장이 만든 파일에만 접근하는 `drive.file`이며, 사용자의 다른 드라이브 파일은 읽지 않습니다. 로그인 토큰은 화면이 열려 있는 동안 메모리에만 보관하고 저장하지 않습니다. 이 데이터는 개발자에게 전송되지 않고 개발자가 접근할 수 없습니다.

## 권한

`unlimitedStorage` 권한은 사용자의 작성 내용이 저장 공간 부족으로 브라우저에서 삭제되지 않게 하려는 목적입니다. 파이어폭스 확장은 구글 로그인을 위해 `identity` 권한(확장의 리디렉션 주소 계산)과 `tabs` 권한(구글 로그인 탭이 돌아온 주소 확인)도 사용합니다. 다른 탭의 주소나 내용은 저장하거나 전송하지 않습니다.

## 데이터 삭제

확장 프로그램을 삭제하거나 브라우저의 사이트 데이터를 지우면 브라우저에 저장된 내용이 삭제됩니다. 연결한 폴더의 파일은 사용자가 직접 관리합니다.
