# 인과 편집기 개인정보처리방침

시행일: 2026년 11월 15일

인과 편집기(이하 "확장 프로그램")는 사용자의 데이터를 수집하거나 외부 서버로 전송하지 않습니다.

## 수집하는 정보

없습니다. 개발자는 이름, 이메일, 위치, 방문 기록, 사용 기록 등 어떤 사용자 정보도 수집하지 않습니다. 분석 도구, 광고, 추적 코드도 사용하지 않습니다.

## 데이터 저장 위치

사용자가 편집기에서 작성한 노드, 화살표, 설정, 버전 기록은 다음 두 곳 중 한 곳에만 저장됩니다.

- 사용자의 브라우저 안(IndexedDB). 기본값입니다.
- 사용자가 직접 연결한 컴퓨터의 폴더. 사용자가 선택한 경우에만 사용합니다.

이 데이터는 사용자의 기기 밖으로 나가지 않으며 개발자를 포함한 누구에게도 전송되지 않습니다.

## 외부 통신

확장 프로그램은 외부 서버와 통신하지 않습니다. 외부 스크립트를 내려받아 실행하지도 않습니다. 편집기 화면의 "책 소개" 링크는 사용자가 직접 눌렀을 때만 새 탭으로 열리는 일반 링크입니다.

## 권한

`unlimitedStorage` 권한만 사용하며, 사용자의 작성 내용이 저장 공간 부족으로 브라우저에서 삭제되지 않게 하려는 목적입니다.

## 데이터 삭제

확장 프로그램을 삭제하거나 브라우저의 사이트 데이터를 지우면 브라우저에 저장된 내용이 삭제됩니다. 연결한 폴더의 파일은 사용자가 직접 관리합니다.
