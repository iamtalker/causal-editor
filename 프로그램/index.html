인과 편집기

노드나 화살표를 클릭하면 여기에서 내용을 편집할 수 있습니다.
사용법은 상단의 도움말 버튼을 누르세요.

도움말

  • 빈 곳 더블클릭: 노드 추가 (노드 = 하나의 상태)
  • 캔버스에서 마우스 오른쪽 버튼: 대상에 맞는 편집 메뉴
  • 빈 캔버스를 누른 채 드래그: 화면 이동
  • 노드 드래그: 위치 이동
  • 노드 선택 후 Shift+클릭 다른 노드: 화살표 연결 (원인 → 결과)
  • 화살표를 클릭하면 그 인과의 설명과 메모를 적을 수 있습니다
  • 노드·화살표 선택 후 Delete: 삭제
  • 노드 오른쪽 위 체크박스: 체크한 노드는 초록색, 현재 선택한 노드는 파란색 테두리로 표시됩니다
  • 양 끝 노드가 모두 체크된 화살표는 체크 강조 색으로 표시됩니다
  • 포커스 모드: 선택 노드와 바로 연결된 노드만 표시합니다. 체크 강조와는 별개이며, 포커스 종료를 누르면 전체 그래프가 다시 보입니다
  • 노드 편집 칸에서 시작·종료 노드를 정하면 계층, 피라미드, 다이아몬드 정렬의 기준이 됩니다
  • 설정: 노드 모양, 노드 색, 배경 색, 연결선 모양과 색, 체크 강조 색, 선택 강조 색을 바꾸고, JSON 저장·불러오기도 여기서 합니다

그래프 버전 기록

앱을 열거나 주기를 적용한 때부터 설정한 간격으로 그래프를 확인합니다. 마지막 버전과 달라졌을 때만 전체 스냅샷을 변경이력 폴더에 저장합니다. 이전 버전을 JSON으로 내려받거나 복원할 수 있습니다.

설정

노드 색 (안쪽 채우기)
배경 색
연결선 색
체크 강조 색 (체크된 노드와 연결 화살표)
선택 강조 색 (현재 선택한 노드 테두리)
그래프 주위에 확보할 빈 작업 공간입니다. 전체 그래프 보기에도 포함됩니다.
