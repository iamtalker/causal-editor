인과 편집기

인과 그래프 하나를 편집합니다. 그래프 JSON과 노드 Markdown은 노드파일 폴더에 저장됩니다.

노드나 화살표를 클릭하면 여기에서 내용을 편집할 수 있습니다.
사용법은 상단의 도움말 버튼을 누르세요.

도움말

  • 빈 곳 더블클릭: 노드 추가 (노드 = 하나의 상태)
  • 캔버스에서 마우스 오른쪽 버튼: 대상에 맞는 편집 메뉴
  • 빈 캔버스를 누른 채 드래그: 화면 이동
  • 상단 검색: 노드 제목과 메모를 검색하고, 결과를 누르면 해당 노드로 이동합니다
  • 상단의 굽은 화살표 버튼 또는 Ctrl+Z / Ctrl+Y: 편집 되돌리기·다시 실행 (Ctrl+Shift+Z도 다시 실행)
  • 노드 드래그: 위치 이동
  • 노드 선택 후 Shift+클릭 다른 노드: 화살표 연결 (원인 → 결과)
  • 화살표를 클릭하면 메모를 적을 수 있습니다
  • 노드·화살표 선택 후 Delete: 삭제
  • 노드 역할은 화살표 연결에 따라 자동 결정됩니다. 나가는 화살표만 있으면 시작, 들어오는 화살표만 있으면 목표, 둘 다 있거나 화살표가 없으면 일반입니다
  • 노드를 선택해 진행 상태(미착수·진행 중·완료·중단·실패)와 메모를 편집합니다. 상태와 자동 역할에 따라 표시가 달라집니다
  • 포커스 모드: 버튼을 누른 뒤 시작 노드를 선택하면 화살표 방향으로 이어지는 경로를 표시합니다. 선택 노드로 들어오는 화살표는 경로에 포함하지 않으며, 포커스 중 다른 노드를 선택해도 경로는 고정됩니다. 새로 만든 노드와 그 연결 화살표는 포커스 종료 전까지 계속 표시되어 편집·삭제할 수 있습니다
  • 설정: 노드 모양, 노드 색, 배경 색, 연결선 모양, 선택 강조 색을 바꾸고, JSON 저장·불러오기도 여기서 합니다
