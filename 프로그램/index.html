인과 편집기

책 소개
인과 그래프 하나를 편집합니다. 노드 Markdown 파일(노드파일 폴더)이 원본이며, 그래프 JSON은 내부데이터 폴더에 보조로 저장됩니다.

노드나 화살표를 클릭하면 여기에서 내용을 편집할 수 있습니다.
사용법은 상단의 도움말 버튼을 누르세요.

도움말

편집

  • 빈 곳 더블클릭: 노드 추가
  • 노드 더블클릭: 그 자리에서 제목·메모·진행 상태 편집 (제목 Enter 또는 메모 Ctrl+Enter 저장, Esc 취소, Tab 칸 이동, 사이드바를 열지 않아도 됩니다)
  • 노드 선택 후 Shift+클릭 다른 노드: 화살표 연결 (원인 → 결과)
  • 노드·화살표 클릭: 오른쪽 패널에서 진행 상태와 메모 편집
  • Delete: 선택한 노드·화살표 삭제 / 마우스 오른쪽 버튼: 편집 메뉴
  • 노드 드래그: 위치 이동 / 빈 곳 드래그: 화면 이동
  • Ctrl+Z, Ctrl+Y(Ctrl+Shift+Z): 되돌리기·다시 실행

진행 상태

  • 시작·미착수·진행 중·완료·중단·실패·종료. 시작과 종료는 화살표가 아니라 진행 상태로 직접 정합니다
  • 상태에 따라 노드 색이 달라지며, 색은 설정에서 바꿀 수 있습니다
  • 노드를 선택하면 그 노드에 연결된 선이 검정으로 굵게 표시됩니다

보기·정렬

  • 상태 보기: 고른 상태의 노드는 진하게, 나머지는 흐리게 표시하고 검색 목록도 그 상태만 보여 줍니다 (파일에 저장되지 않는 화면 설정)
  • 간편 보기: 노드를 제목 한 줄짜리 작은 상자로 표시합니다
  • 포커스 모드: 시작 노드를 고르면 그 노드에서 화살표 방향으로 이어지는 경로만 표시합니다. 포커스 중 새로 만든 노드는 계속 보이며, 종료하면 전체가 다시 보입니다
  • 정렬: 피라미드, 역피라미드, 다이아몬드, 원형, 격자, 트리 탑다운·바텀업, 연결 많은 순

찾기

  • 상단 검색: 노드 제목·메모를 검색하고 결과를 누르면 그 노드로 이동합니다. 검색창이 비어 있을 때 누르면 연결(화살표)이 많은 순서의 목록이 나옵니다

저장

  • 편집 내용은 노드 파일로 자동 저장됩니다. 설정에서 색·모양·연결선을 바꾸고 JSON 저장·불러오기, 데이터 폴더 지정도 할 수 있습니다

설정

화면

그래프 주위에 확보할 빈 작업 공간입니다. 전체 그래프 보기에도 포함됩니다.

색

기본 노드 색 (미착수 노드의 안쪽 색)
배경 색
진행 상태 색
노드 테두리·상태 점·연결선에 쓰이고, 노드 안쪽은 이 색을 옅게 칠합니다. 미착수 노드의 안쪽은 위의 기본 노드 색입니다.

연결선

끄면 A에서 B로 연결된 상태에서 B에서 A로의 화살표 연결을 막습니다. 켜면 서로 연결되는 화살표를 만들 수 있지만 선이 복잡해집니다.
